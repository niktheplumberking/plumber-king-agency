## 8. Component map

How to read it: each row is one section. **Use** = the 21st.dev component the build pulls (fact: found in the 21st.dev catalog today, link opens it). **Backup** = a second 21st.dev option. **3rd ref** = a search on Dribbble / Land-book / Awwwards / Pinterest; the exact shot gets picked and logged when the Figma stage starts (not picked yet). Everything is restyled in Mike's own brand (his logo colours, font and real photos). **Layout** says how it must look, so no layout repeats anywhere on the site.

Rule checks built into this map:
- Every component in the **Use** column is used **once** on the whole site (a backup may be another row's pick). Only the shared parts (header, utility bar, emergency strip, footer) repeat, because they are the same element on every page.
- Reviews have **8 different layouts** (one per page). FAQs have **7 different layouts**. Each closing CTA is different.
- Nothing copies United or Paul's look. Their structure only.
